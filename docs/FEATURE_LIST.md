# Feature List - TalkNow

## 1. Visitor-Facing Features (The Widget)
- **Omni-channel Widget:** A single floating button providing access to multiple contact methods.
- **Live Chat:** Real-time text communication with business agents.
- **Meeting Scheduler:** Integration with Google Meet and Zoom for automated video call booking.
- **WhatsApp Lead Capture:** One-click redirection to WhatsApp with a pre-filled message.
- **Call Request:** Form to request a callback from the sales team.
- **Automated Greeting:** Configurable welcome message to engage visitors upon page load.
- **Responsive Design:** Fully optimized for mobile and desktop browsers.

## 2. Business Owner Features (The Dashboard)
- **Real-time Dashboard:** Overview of total leads, bookings, and active sessions.
- **Widget Customizer:**
  - Change primary/secondary colors.
  - Update agent names and photos.
  - Configure business hours and contact information.
- **Lead Management:**
  - Centralized inbox for all leads.
  - Detailed visitor metadata (Browser, OS, Location, Referral source).
- **Meeting Management:** View and manage upcoming Google Meet/Zoom bookings.
- **Team Management:** Invite and manage agents with different permission levels.
- **Integration Hub:**
  - Connect Google Calendar for availability syncing.
  - Connect Zoom for automatic meeting link generation.
- **Subscription & Billing:**
  - Plan selection and upgrade path via Razorpay.
  - Invoice history and lead usage tracking.

## 3. Analytics & Tracking (Advanced Features)
- **Session Recordings:** Record and playback visitor interactions on the website.
- **Heatmaps:** Visual representation of where visitors are clicking and scrolling.
- **Visitor Timeline:** Detailed event log for each session (page views, button clicks).
- **Plan-based Gating:** Advanced analytics automatically enabled for Pro/Premium users.

## 4. Super Admin Features
- **Global Overview:** Monitor platform health and total business count.
- **Business Management:** View, edit, or suspend business accounts.
- **Plan Management:** Adjust lead limits and pricing for all subscription tiers.
- **System Logs:** Review platform-wide errors and security events.

## 5. Technical Features
- **Shadow DOM Isolation:** Ensures the widget doesn't break the host website's styling.
- **JWT Authentication:** Secure access for dashboard and API routes.
- **Socket.io Integration:** Powering real-time updates for chat and notifications.
- **Email Notifications:** Automatic alerts for new leads via SendGrid.
